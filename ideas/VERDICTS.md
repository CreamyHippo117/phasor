# Verdicts

The owner's judgment of ideas after a full scene plan (or after making the video). The
`scene-brainstorm` skill reads this before every run and never writes in it.

One entry per idea, in the owner's own words:

```
## <slug or working title>   (date)
Verdict: held up | fell over
Why:
What the scout should learn from it:
```
