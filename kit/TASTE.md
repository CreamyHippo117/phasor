# Taste

What the person likes and dislikes, newest last. Read before every scene; it outranks the
examples. Add a dated line whenever they say something about taste.

- Dark by default (`midnight_glow`); light themes only when asked.
- The reference style is the prism look (`kit/examples/complex/prism_primes.py`): glowing
  strokes, a spectrum along curves, calm pacing.
- Fewer rainbows is not no rainbows: color that carries meaning (domain-coloring phase)
  keeps the full wheel.
- 2026-11-25: the reference for teaching and look is 2swap ("don't flip, algebra inside"
  6:55-7:10; "i'm so bad at billiards that i ended up in the hyperbolic plane" 5:00-5:40).
- 2026-11-25: one animation owns the stage: full frame on midnight black, alone, for as
  long as it needs (iterations, new cases, a parameter turning). Full, bright color is
  welcome when the mathematics is that full.
- 2026-11-25: the animation does the talking: explain briefly, then let it run in silence
  over ambient music; explain more afterwards only if needed. Never rush.
- 2026-11-25: quality, not quantity: as many animations as the best story needs (ten or
  three), none added to fill time.
- 2026-11-25: open with a question, let the viewer predict, come back to the same picture
  with new cases; usually not concrete before abstract (ask which route).
- 2026-11-25: not much text or equations on screen; no hard cuts, one animation becomes
  the next.
- 2026-11-26: a long hold milks extensions of the same idea (the next case, the parameter
  going further, a deeper level, another view), never a replay of the exact same visual.
